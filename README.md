# AutoSense

**AI-Based Autoimmune Disease Prediction System**

AutoSense is a machine learning-based project aimed at assessing the possibility of multiple autoimmune diseases based on patient-related data.

## Project Overview

The project focuses on identifying patterns in patient information, symptoms, and other relevant clinical features to estimate the possibility of different autoimmune diseases.

Instead of predicting only one disease, AutoSense aims to provide individual possibility scores (percentages) for six selected autoimmune diseases.

## Selected Diseases for Reference

The project currently focuses on the following six diseases:

1. Rheumatoid Arthritis (RA)
2. Type 1 Diabetes (T1D)
3. Multiple Sclerosis (MS)
4. Inflammatory Bowel Disease (IBD)
5. Psoriasis
6. Hashimoto's Thyroiditis

## Proposed Approach

- Use patient-related datasets for the selected diseases.
- Perform data preprocessing and feature handling.
- Explore and train suitable machine learning models.
- Estimate individual disease possibility scores.
- Present the results in a combined dashboard.

## Project Objective

To explore the use of machine learning in analyzing patient data and providing insights into the possibility of multiple autoimmune diseases.
